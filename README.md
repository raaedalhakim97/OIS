# CinGen

AI-powered cinematic video generation engine (CineEngine).

## Structure

- `cineengine/camera/` — camera motion, easing, shake, splines
- `cineengine/effects/` — bloom, blur, chromatic, color grade, DOF, glow, grain, particles, vignette
- `cineengine/ai/` — depth, segmentation, optical flow, captioning, story, prompt, image generation
- `cineengine/audio/` — audio mix, beat detection, ASMR, music, sync
- `cineengine/subtitles/` — subtitle rendering, animation, typography
- `cineengine/renderer/` — compositor, timeline, transitions, export

## Usage

See `cineengine/main.py` for an example. Install dependencies with `pip install -r cineengine/requirements.txt`.
